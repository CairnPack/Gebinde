# Gebinde

A toolchain for Minecraft modpacks: a modpack is a version-controlled, reproducible project, and the instance directory *is* the project root. The CLI is `gebinde`; the manifest is `gebinde.toml`.

Gebinde is maintained by cairnpack and is under early development; nothing is usable yet.

## Building

Requires the .NET 10 SDK.

```sh
dotnet build Gebinde.slnx
```
